# 언제 만나? 📅

내 일정이 있는 달력을 친구에게 보내면, 친구가 만날 수 있는 날짜를 골라서 답장해 주는 웹앱입니다.
서버나 로그인 없이 `index.html` 파일 하나로 동작하고, 모든 데이터는 링크 안에 담겨요.

## 사용법

1. **내 일정 표시** – `index.html`을 열고 이름을 입력한 뒤, 일정이 있는 날을 달력에서 탭하세요. 날짜마다 메모(예: 회식)를 붙일 수 있어요.
2. **링크 보내기** – "친구에게 보낼 링크 만들기"를 누르면 링크가 만들어지고, 카톡 등으로 공유하거나 복사할 수 있어요.
3. **친구가 날짜 고르기** – 친구가 링크를 열면 내 일정이 있는 날(빨간색)은 고를 수 없고, 나머지 날짜 중 만날 수 있는 날을 여러 개 골라요.
4. **답장 확인** – 친구가 "답장 보내기"로 만든 링크를 나에게 보내면, 만날 수 있는 날(초록색)이 달력과 목록으로 보여요.

## 배포 (GitHub Pages)

친구가 링크를 열 수 있으려면 인터넷에 올려야 해요.

1. GitHub 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main` / `(root)` 선택 후 저장
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있어요.

## 참고

- 일정 정보는 링크(`#` 뒤) 안에 인코딩되어 있어서 서버에 저장되지 않아요. 링크를 가진 사람은 누구나 내용을 볼 수 있어요.
- 지난 날짜는 고를 수 없어요.
